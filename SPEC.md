# compass — protocol specification

**Spec version:** 3 — bump this when a convention below changes.

Version 3 is implemented by the Go `compass` binary (`cmd/compass`, `internal/compass`). Why:
[positioning.md](.compass/context/positioning.md) and [decision 0015](.compass/decisions/0015-scope-cut.md).

## Files
```
.compass/
  INDEX.md                    generated by `compass index`; never edited by hand
  context/current-state.md    the front door; overwritten whole, never patched
  context/*.md                standing context (conventions, environment), never plans: records
  decisions/NNNN-slug.md      records
  goals/YYYY-MM-DD-slug.md    records
  experiments/YYYY-MM-DD-slug.md  records
  scratch/                    gitignored, never read by compass
```
Any other folder (v2's `logs/`, `learnings/`, `environment/`, `architecture/`) is not read; the
index counts its files. `archive.md` files are not records.

## Records
A record is a dated, immutable statement. Its text is never edited after it lands; a later record
replaces it with `supersedes:`. Frontmatter is a YAML subset: `key: value`, `key: [a, b]`, or a
key followed by `  - item` lines; double-quoted values are unquoted; block scalars (`>`, `|`) are
refused; nested maps are ignored.

| Field | Required | Meaning |
|---|---|---|
| `claim` | yes | One line, at most 200 characters: what holds. `description` is accepted in its place. |
| `date` | no | `YYYY-MM-DD`; else a body `Date:` line; else the filename's date prefix. |
| `scope` | no | `global` (delivered by every resume while live) or `local` (the default). |
| `supersedes` | no | IDs (`0006`, `0006-slug`, `2026-01-01-slug`) or paths of the records this replaces. A v2 body line `Supersedes: NNNN` is read too. |
| `premises` | no | What the record rests on; `goal:<slug>` names a goal record. |
| `refs` | no | Paths (from the repo root, from `.compass/`, or from the record) and `commit:<hash>` are checked; other `scheme:` refs belong to other tools and are not. |
| `status` | **never** | Derived: a record is superseded when a live record's `supersedes:` names it. |

A record is at most 300 lines. A body of nothing but headings (`compass record`'s skeleton, unfilled)
warns `record-body-empty`, and `compass record` says so on stderr when it writes one. When it
supersedes, `compass record` names each claim it retires, and says when dropping `scope: global`
stops resume delivering it. Two live records superseding the same one warn `supersedes-forked`.

## current-state.md
Last known intent, at most 80 lines: `## Objective` and `## Next steps`, never a plan (a plan
lives with the task: a PR, an issue, a scratch file). Where it disagrees with git or the user's
current prompt, git and the prompt win and it is rewritten. A `<...>` template placeholder is not
content. A `Commit:` line holds the full or
abbreviated hash of HEAD when it was written (`git rev-parse HEAD`). It is **stale** when commits
that change anything outside `.compass/` exist after the later of the anchor and the last commit
that changed current-state.md.

## Commands and checks
`compass check` exit status is 1 on any error; warnings never fail it. Codes:
`record-unparseable`, `claim-missing`, `claim-too-long`, `status-handwritten`,
`record-too-long`, `scope-invalid`, `supersedes-dangling`, `supersedes-self`, `supersedes-cycle`,
`supersedes-ambiguous`, `ref-unresolved`, `current-state-too-long`,
`anchor-missing`, `anchor-malformed` (errors); `current-state-missing`, `anchor-unresolved`, `next-steps-missing`,
`agents-block-drift`, `record-body-empty`, `supersedes-forked`, `index-stale`, `decision-number-duplicate` (warnings); `anchor-stale` (a warning, an error with
`--require-fresh`). `--fix` regenerates the index and stamps HEAD into an anchor that is missing,
malformed, or names no commit; it never restamps a real but stale anchor.

`INDEX.md` is capped at 2,000 estimated tokens (bytes/3); every non-empty section keeps its heading
and a pointer to what didn't fit. The resume brief is current-state, live `scope: global` records,
the commits since current-state was written, `git status` and `git diff --stat HEAD`, each capped;
the SessionStart hook injects it, cut to 9,500 characters by current-state section, after compaction or a
resumed session, with uncommitted changes (submodules count only when their commit moved) or a
failed `git status`, when an old Python compass-cli shadows the binary, or when current-state is stale or its freshness unknown;
otherwise it injects a stub of at most 500 characters (the objective, the live next step, and a
pointer to `compass resume`).

## AGENTS.md and CLAUDE.md
In files the user owns, compass writes only: the block between `<!-- compass:begin ... -->` and
`<!-- compass:end -->` in `AGENTS.md`, one pointer line in `CLAUDE.md`, one line each in
`.gitignore` (`.compass/scratch/`, or `.compass/` when branch-local) and `.gitattributes`
(`.compass/INDEX.md merge=union`), and a git pre-commit hook only where none exists (or its own,
refreshed).

## Hooks
`compass hook session-start|stop|pre-compact` read Claude Code's JSON on stdin and always exit 0.
`compass hook pre-commit` checks `.compass/` as staged (paths in refs must be staged
too), stages the index generated from the staged records, and exits 1 on errors.


## Delivery checks
Claude Code fails quietly when it can't load the plugin: an unreadable user `settings.json` (a
dangling symlink, invalid JSON) means no hooks and no plugins, and the session doesn't say so. The
SessionStart hook can't report its own absence, so three other places do, reading (never writing)
`$CLAUDE_CONFIG_DIR` or `~/.claude` (`settings.json`, `plugins/installed_plugins.json`) and the
project's `.claude/settings.json` and `.claude/settings.local.json` at cwd and the repo root:
- `compass doctor` lists each problem with its fix, names the config dir it read, and exits 1.
- `compass resume` and `compass hook pre-commit`, inside Claude Code (`CLAUDECODE=1`, inherited by
  git hooks), print `compass: warning: …` per problem to stderr; resume's stdout and pre-commit's
  exit status are unchanged.
- The AGENTS.md block tells agents the brief arrives on its own in Claude Code (a message starting
  `compass:`) and to run `compass doctor` and tell the user when it didn't.

Problems: user settings unreadable; `disableAllHooks: true`; v2 hook registrations
(`tool-routing-guard`, `session-context-nudge`, `compass-session-start`); and, where Claude Code is
meant to run compass (`CLAUDECODE=1`, a `compass@` key in settings, or an installed entry), the
plugin not installed (user scope, or project/local scope for this project), its install directory
missing, or its installed key enabled nowhere (per-key precedence: user, project, local; a stale
`compass@<old marketplace>: true` enables nothing). `disableAllHooks` resolves by the same
precedence. A UTF-8 BOM is accepted, as Claude Code accepts it. Unknown shapes (an unreadable plugin
registry skips the install checks), malformed project settings, a missing `hooks/hooks.json` under
the install path, and a missing plugin without that intent are notes.
An older compass first on PATH: the agent's shell runs it, not the plugin's. The SessionStart hook
(the plugin's binary) runs `version` on the first `compass` on its PATH when that is an absolute
entry outside `CLAUDE_PLUGIN_ROOT` that looks like compass (Mach-O, ELF, or a script naming
compass), at most once, 1 s timeout, its process group killed and its output capped; never one inside the project; when it is a Go compass older than the plugin's, the full brief
says so and names the plugin's binary. Doctor flags a first Go compass older than itself or the
installed plugin's highest version. Versions compare by dotted number; anything else never warns.
Not seen: `--plugin-dir`/`--settings` flags and managed settings. compass names the fix and never
edits Claude Code's config. `tests/e2e.sh` installs the plugin into a clean config dir with the
`claude` CLI and checks delivery, the dangling-symlink failure, and a control that must fail.
