# Disposable sessions: any agent, Claude or not, resumes the work without a discovery phase

## Goal
Any agent session is disposable: an agent (Claude or not) starts informed without a discovery
phase, and work resumes on a different agent when one hits its usage limit.

## Why
See [positioning.md](../context/positioning.md): expensive resumes and uninformed reversals.
