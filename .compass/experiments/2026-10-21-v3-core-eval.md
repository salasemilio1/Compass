# v3 core eval: resume cost, discovery overhead, cross-agent handoff

Status of this file: **protocol written before the synthetic runs** (committed first, so git shows
it predates the results). Results are appended below it in a later commit.

## Fixture
- `git clone --no-hardlinks ~/Dev/Misc/personal-dashboard` (ebay-flipper) at `931d4ad`, branch
  `feat/notify-clarity-and-pricing`, remote removed, in the session scratchpad. The original is
  never written; its `.compass/` was diffed against the clone (identical except gitignored files).
- Every run gets a fresh copy of its arm.

## Part 1: resume cost (static)
Run `compass check`, `compass index`, `compass resume` and the SessionStart hook on the copy.
Token counts use Claude's tokenizer: a one-turn, tool-less `claude -p --setting-sources project`
whose prompt is "Reply OK." plus the file's content, minus the same run without it (median of 3).

## Part 2: discovery overhead (synthetic sessions)
**Arms**
- **A, none:** `.compass/` and `graphify-out/` deleted; the "uses the compass protocol" line removed
  from `CLAUDE.md` and `AGENTS.md` (the rest of `CLAUDE.md`, the project's hand-written contract,
  stays: that is what a repo without compass has).
- **B, v2:** as cloned. `CLAUDE.md` says "Read `.compass/INDEX.md` first" (121 KB).
- **C, v3:** the v2 pointer line removed; `current-state.md` restated to at most 80 lines by one
  Sonnet pass from the original (the cap v3 enforces; the same restated file for every C run);
  `compass index`; `compass init --no-git-hook`; the plugin loaded with `--plugin-dir`.

**Harness:** `claude -p --setting-sources project --model sonnet --output-format stream-json`,
`--permission-mode acceptEdits`, tools Read, Grep, Glob, Edit, Write and Bash, `--max-turns 60`.
`--setting-sources project` keeps the user's global hooks, plugins and settings out of every arm.

**Tasks (prompts verbatim)**
- **T1:** "The photo reconciler rejects bare GPU model tokens like `5060` or `4080` written without
  `RTX`. Decide whether it should accept them; if yes, implement it with tests, if no, explain why.
  Don't commit."
- **T2:** "`reviewCandidateSeen` holds its fast-lane slot until the availability check ends, up to
  5 s after finalize. Make it release the slot once the review is finalized, with a test. Don't
  commit."

2 runs per arm and task: 12 runs.

**Metrics** (from the stream-json transcript, by script)
- Discovery calls: Read, Grep, Glob and Bash calls before the first Edit or Write. T1 may end with
  no edit (a "no"), in which case all calls count and the run is marked "no edit".
- Context at first edit: input + cache-creation + cache-read tokens of the assistant turn that
  issues the first edit (what the agent had read by then).
- Total cost, turns.
- Outcome, graded by rubric written now:
  - T1 pass: declines and names the serial/part-number risk (the code's own comment), or accepts
    bare tokens only under a guard that addresses that risk (for example only when the listing's
    reference model has the same number), with tests; `go test ./internal/deals/` passes.
  - T2 pass: the slot is released at finalize, the availability check still runs, a test covers
    it, `go test ./internal/deals/` passes.

**Bar, set before the runs:** v3 (C) must have at least 30% less median context at first edit
than v2 (B), with no worse pass rate. Against A, v3 should show fewer discovery calls; if C is not
below A on discovery calls, compass's front door is not paying for itself on these tasks.

## Part 3: mid-task handoff, Claude to Codex
- **H-v3 (arm C, with `current-state` naming T2 as the next step):** agent 1 = Claude Sonnet,
  prompt "Do the next step from current-state.", cut off by `--max-turns` while its edits are
  uncommitted. Agent 2 = Codex (`codex exec`, its default model), cold, with the Go `compass` first
  on PATH and only `AGENTS.md` to go on; prompt "Continue the work in this repository."
- **H-control (arm A):** the same cut-off agent 1 with the T2 prompt; agent 2 = Codex given the T2
  prompt again (the human re-pastes the task, which is what happens without compass).
- Scores: agent 2 finishes T2 to the T2 rubric; its discovery calls before its first edit; whether
  it found the task without being told (H-v3 only).
- Known noise: Codex loads the user's own `~/.codex` skills (seen in the live test), in both arms.

# Results (2026-10-21, after the runs)

Raw transcripts, diffs and test logs stayed in the session scratchpad (they contain the private
repo's code); the numbers below are extracted from them by `metrics.py` (Claude stream-json) and
`codex_metrics.py` (Codex `--json`).

## Part 1: resume cost (static)
| What a fresh agent is given | Bytes | Tokens (Claude tokenizer) |
|---|---|---|
| v2 front door: INDEX.md + current-state.md | 121,468 + 23,505 | 38,121 + 7,694 = **45,815** |
| v3 SessionStart brief (capped at 9,500 chars) | 9,447 | **3,102** |
| v3 `compass resume`, uncapped | 24,306 | 7,945 |
| v3 generated INDEX.md (read on demand) | 7,966 | 2,723 |

- v3's injected brief is **93% smaller** than v2's front door; even the uncapped brief plus the index
  is 77% smaller. The brief is cut from the middle because ebay's current-state is 344 lines
  (cap 80).
- `compass check` on the unmigrated v2 data: 181 `claim-missing` (104 context plans, 59 decisions,
  18 experiments), 37 `record-too-long` (all context plans), 23 `claim-too-long`, plus
  `current-state-too-long`, an anchor not in HEAD's history (`anchor-unresolved`: ebay rebases),
  and one stale anchor. check ran in 0.12 s, resume in 0.24 s.
- **bytes/4 undercounts by ~30%** on this text (2.9-3.2 bytes per token measured), so the token
  estimate moved to bytes/3.

## Part 2: discovery overhead (12 runs, Sonnet)
| Run | Discovery calls before first edit | Context at first edit | Cost | Outcome |
|---|---|---|---|---|
| A-T1 ×2 | 10, 10 | no edit (declined) | $0.40, $0.26 | pass, pass |
| B-T1 ×2 | 6, 9 | no edit (declined) | $0.31, $0.24 | pass, pass |
| C-T1 ×2 | 11, 11 | no edit (declined) | $0.47, $0.39 | pass, pass |
| A-T2 ×2 | 7, 4 | 69.6k, 65.1k | $2.32, $2.47 | test added, suite passes (both hit 60 turns) |
| B-T2 ×2 | 24, 13 | 81.3k, 63.9k | $1.57, $1.35 | test added, suite passes (one hit 60 turns) |
| C-T2 ×2 | 10, 22 | 64.0k, 93.0k | $1.84, $1.66 | test added, suite passes (one hit 60 turns) |

- **The bar failed.** T2 median context at first edit: A 67.3k, B 72.6k, **C 78.5k** (v3 is 8% above
  v2, not 30% below). C was not below A on discovery calls for either task.
- Every arm passed both rubrics. In T1 all six runs declined and cited the serial-number risk,
  found in the code's own comment and a named test; no arm reversed the design. The "comment the
  why" layer did the work; compass wasn't needed for it.
- **No arm used its front door.** The v2 runs never opened the 121 KB INDEX.md that `CLAUDE.md` told
  them to read first; the v3 runs never ran `compass resume` or opened INDEX.md. Both found the
  relevant `.compass/` plans (`photo-ocr-plan.md`, `owned-latency-profiler-plan.md`) by grep. With
  a specific task in the prompt, agents go straight to the code.
- So on fresh, fully specified, code-local tasks the SessionStart brief is a fixed ~3.1k-token
  cost (about 5% of the ~60k context at first edit) with no measured return. v2's front door costs
  nothing in practice when skipped, and 45.8k when its warm-up runs.

## Part 3: handoff, Claude to Codex
Agent 1 (Sonnet) was cut off by `--max-turns` with uncommitted edits to `fastlane.go` and
`availability.go` in both arms (the v3 agent needed 22 turns; at 14 it was still reading).
**Neither agent 1 rewrote current-state before it was cut off**, despite the AGENTS.md rule; a
usage-limit cut fires no Stop hook, so only `git status` and the diff carried its work.

| Agent 2 (Codex) | Found the task | Commands before first edit | Input tokens | Finished T2 |
|---|---|---|---|---|
| Control (arm A): T2 prompt re-pasted | given | 11 (24 total) | 2.89M | yes: kept agent 1's edits, regression test proven to fail on the old code, `make lint test build` pass |
| v3: "Continue the work in this repository." | **yes, from `compass resume` alone** (task + agent 1's partial edits) | 9 | 0.20M | no: stopped to ask for the `/new-test` skill ebay's AGENTS.md requires |
| v3 rerun (deviation: + "if AGENTS.md names a skill you don't have, follow its intent") | yes | 43 (68 total) | 4.04M | yes: kept agent 1's edits, tests added, `make test build` pass, current-state rewritten |

- **Cross-agent resume works:** with no prompt beyond "continue", Codex ran `compass resume` first,
  named the task and agent 1's partial edits correctly, and finished it without redoing them.
- **It was not cheaper** than a human re-pasting the task: 43 vs 11 commands before the first edit,
  1.4× the tokens. Part of that is noise compass doesn't control (Codex read five of the user's own
  `~/.codex` skills); part is that an open "continue" invites wider exploration; and part was
  compass's own: Codex re-read current-state and INDEX.md after `compass resume` had printed them
  (the CLI brief now says it contains current-state).
- ebay-flipper's AGENTS.md is a Claude contract (it names Claude skills), which blocked a
  non-Claude agent until told to follow intent. Repos that want cross-agent resume need an
  agent-neutral AGENTS.md.

## Other findings
- **Capping current-state is lossy when an agent restates it.** The one-pass Sonnet restatement to
  80 lines dropped both next steps the tasks came from, despite "keep every next step", and invented
  5 paths under "files in play". `compass check` caught all 5 (`file-in-play-missing`).
- A live Haiku session typed an invented hash into `Commit:`; check now restamps an anchor that
  names no commit, and the block says to use `git rev-parse HEAD`.

## Verdict
- **Resume cost: confirmed.** The v3 brief is 93% smaller than v2's front door on the largest real
  `.compass/` there is.
- **Discovery overhead: not shown.** On specified, code-local tasks no form of compass reduced
  discovery; agents read code. This is the best case for "no compass", and n = 2 per cell with one
  model and one repo, so it bounds rather than settles the question.
- **Cross-agent handoff: works for continuity, not for cost.** `compass resume` alone carried the
  task across agents; it didn't make the second agent cheaper than a re-pasted prompt.
- Implication for the gate: nothing here argues for building delivery-plan.md's decision delivery;
  the one reversal risk tested was guarded by a code comment in every arm.
